# VoIP / Asterisk Engineer — русская страница

Статическая русскоязычная страница-портфолио Анатолия Шешенина с фокусом на Linux-телефонию, изолированную мультитенантную архитектуру Asterisk и CRM-интеграции.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.
